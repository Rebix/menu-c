# Gandom v0.8

Source: https://github.com/rastikerdar/gandom-font/releases/tag/v0.8

`Gandom.woff2` is the unmodified standard font from the official release.
It includes Persian and Latin characters and preserves each digit's script.
Only the regular weight is available; browsers synthesize bold for existing
bold text. The font is self-hosted, preloaded by the shared layout, and used
as Tailwind's default sans font with `font-display: swap`.
